# Vectorstores

Example Vectorstore manifests: vector databases for retrieval-augmented generation, on Pinecone, on Qdrant Cloud,
and on Qdrant that Smarter runs on its own Kubernetes cluster. Each file's header says what it needs, e.g. where a
cloud service's API key comes from, and how to deploy it and add documents.

Every platform applies them for its admin, and deploys none of them.

Documentation: https://docs.smarter.sh/en/latest/smarter-resources/smarter-vectorstore.html
